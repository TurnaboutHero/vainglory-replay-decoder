## Skill investment, rank and restoration

Outgoing `0436` requests a native ability slot. Incoming `043a` can apply point
investment only after object resolution, effective unspent-point and hero-level
requirements. An observed action does not prove the branch accepted it.

Rank is a three-bit field, and its raw setter masks rather than saturates.
Prerequisites use current minus base rank: ordinary requirements are 1 (or 2),
2, 4, 6, 8; the alternate sequence is 6, 9, 12. Overdrive equality is a separate
condition from the selected rank-five property bonus. A missing resolved slot
has an explicit implementation edge; it is not a universal gameplay rule.

Spawn restoration sets absolute ranks and synchronizes linked slots independently
of point spending. Downgrade refund depends on the mode byte. Initial display
selectors differ by hero, and runtime overrides must remain separate from UI
position. There is no universal native slot 2 for every ultimate.

Eleven portable tests cover selected rank algebra, prerequisites, equality,
masking, grant preconditions and curated resource/corpus facts. Learned-rank
property algebra explicitly excludes rank zero and does not emulate native
float32 behavior. The public fixture contains only counts and selected structured
fields, without raw replay payload samples or decoded asset contents.

## Hero level, current XP and UI ratio

ordinary model subtracts one old XP threshold per recalculation path, not once
per gained level; new-level-one initialization resets progress instead. Positive

finite-input limits and withholding of unsupported state.
